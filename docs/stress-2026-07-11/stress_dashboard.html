Method

Each run: fresh workspace copy of the example SoC (121-component riscvier library + 97 skills registered) → headless chipchamp -p "…" under a hard wall cap → objective validators (real lint/sim re-runs, file checks, session-transcript analysis) → one JSONL record. Scenario prompts and validators identical across models; failed runs re-ran once after platform fixes landed so no model is penalized for a platform bug. Full data: results.jsonl, transcripts under runs/, harness in scratchpad/stress/.
